This is a full-stack Todo Application built to manage tasks in a simple and user-friendly way. Users can add new todos, view their existing tasks, mark tasks as completed, and delete tasks. The application uses a React/Vite frontend and a Node.js/Express.js backend, with MongoDB Atlas used to store todo data permanently. The frontend communicates with the backend through REST API endpoints, while the backend handles the application logic and database operations.
The project is divided into two main parts: todo-frontend contains the React-based user interface, and todo-backend contains the Express.js server, API routes, controllers, and MongoDB integration. Environment variables are used to keep sensitive information such as the MongoDB connection string private. The application has been deployed online, with the frontend and backend hosted separately and connected to MongoDB Atlas, making the Todo App accessible from different devices through a public URL.
